# @goldenpigeon/dsh-eu4-indexer-engine-win32-arm64

EU4/HOI4 indexer 0.4.0 for win-arm64, matching the upstream engine version. Installed and updated automatically through the exact optionalDependencies of @goldenpigeon/dsh-eu4-indexer, which has its own version. The bin/ directory contains the complete, directly runnable .NET publish output; no .NET SDK, postinstall script or separate engine activation is required. The Node library is available from @goldenpigeon/dsh-eu4-indexer/engine.
